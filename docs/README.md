`modules/m1` 到 `m7` 是七个模块怎么操作。`references/` 按数据库和主题记端点、死路和作图风格。用库名搜索即可，不必从头读到尾。`references/database_availability_2026-09.md` 是 2026 年 9 月的端点快照。现在该请求哪个地址，看 [DATA_SOURCES.md](DATA_SOURCES.md)，不要用那份快照代替当前探测。

使用约定在仓库根目录的 `SKILL.md`。给 Agent 的短指令看那份。维护者看 `docs/`。两边的工具数、端口和深链顺序要一致。`python scripts/check_repo.py` 会查这件事：语法、64 个工具名，以及 `docs/TOOLS.md` 里每个工具名是否用反引号包住。它不访问网络。

## 读的时候先对上这几件事

- 服务面向任意 MCP 客户端。Cursor 的配置只是例子。路径写成 `<仓库路径>` 或 `<仓库绝对路径>`。
- 推荐 stdio。统一服务的 HTTP 默认是 `127.0.0.1:8002`。单独的 `open_tcm_discovery_mcp.py` 只有检索族，默认端口是 8000。
- 在线成功看 `source` 和 `queried_at`。失败看 `error`，或正文是否以 `Error:` 开头。空列表是这次没取到，不是补出来的记录。
- TCMSP 的 OB≥30、DL≥0.18 只用于本页的 `ob`、`dl`。不要和 HERB 的 DL、RDKit 的 Lipinski 或 QED 写成同一道门。
- 对接输出是提议的对接模型。口袋残基必须来自文献。文献共现、方剂集合重叠、试验登记、嵌入、敲除、ADMET 近似和剂量换算都不是疗效。预测靶点不是已记录证据。
- `tcm_align_tcmsp` 只比调用方已经给出的字符串，不访问网站。名称相同不是结构相同。
- 分析图在实体节点少于 300 个时是圆角卡片，到 300 个按种类收成球壳。图例、检索通路、下一步建议和数据源状态是给智能体读的进度，不是疗效结论。

第一次接手，先读科学边界和部署，再按工作流跑一条 `tcm_smart_plan`。要改代码时再读架构和贡献说明。查某个工具的参数，直接看工具总表，不必从路线图倒推。
