# 渲染与组合图风格规范

> 从 S100A8/紫草酸项目论文级图迭代验证得出（多轮视觉评估 9-10/10）。

## 调色板（固定）

| 用途 | 颜色 | HEX |
|---|---|---|
| TLR4（渐变 N→C） | 浅蓝→深蓝 | 0x386BB0 → 0x3A6CAC |
| MD-2 | 青绿 | 0x24B8A8（表面 0x40A699，透明度 0.50/特写 0.65） |
| S100A8（渐变 N→C） | 浅橙→深橙 | 0xFABF73 → 0xEE8C38 → 0xD16119 |
| 配体 LA | 亮绿 | 0x00B85A |
| 口袋残基 | 金黄 | 0xF2C432 |
| 接触虚线 | 黄 | 0xE6A800（对象级 color 设置） |
| 关键残基四色 | 蓝/绿/紫/灰 | 0x258CD9 / 0x33B24D / 0x9459B8 / 0x666666 |
| 红框参数 | 红 | 0xD82828（边框 width 5） |

## 渲染参数（make_figure_pml.py 内置）

```
bg_color white; ray_shadows 0; antialias 2; field_of_view 18
ray_trace_mode 1; ray_trace_gain 0.08        # 轮廓线+微光
fog_start 0.42; fog_end 0.90; depth_cue 1    # 深度雾化
cart_smooth_loops 1; cart_fancy_helices 1
surface_quality 1; ambient 0.30; direct 0.55
reflect 0.15; spec_reflect 0.12; light_count 3
尺寸 3200x2200, dpi 300; 白底+透明底双版本
```

## 标签纪律

1. 链标签：字号 26、色同链色偏深、Z 偏移 +30、无连接线
2. 残基标签：字号 16、黑色、连接线 1.0 宽、扇形展开偏移（label_positions 模式：左上/右上/左下/右下/上/左/右/下 循环）
3. 配体标签：**单原子限定 `and id 2`**（否则全碳重复标签）
4. 标签避让：渲染后视觉检查，重叠时改 offset（±14~16 起）或换残基锚点
5. 主图（overall）不承载残基标签；细节标签只给 detail/pocket 图

## 组合图版式（参考学术期刊对接图）

```
[左：整体结构图 1420w] --gap 260-- [右：放大图 1420w + 细黑外框]
     ↑细黑矩形框(宽4)框选结合域
     两条细黑直线(宽3)：框右上角→放大框左上角；框右下角→放大框左下角（梯形）
[左上：黑底白字圆形 panel 标签 A/B，直径 ~85px]
[底部居中：PDBID-蛋白_配体 命名，黑体 34]
[右下：红色圆角参数框，标题 19 + 数据行 26，每行可独立颜色]
画布：白底，3220x1266 @300dpi
```

**命名规范**：`PDBID-蛋白_配体`，如 `2Z64-TLR4/MD2_S100A8`、`2Z64-TLR4/MD2_Lithospermic acid`

**框选定位法**：--box 坐标系即主图原生像素坐标（3200×2200）。定位方法：
- 蛋白界面 = 两链颜色像素交界区（橙色∩青绿色 bbox）
- 配体口袋 = 配体颜色像素 bbox 外扩 ~60px
- 交界区坐标可用像素颜色扫描脚本获取（RGB 阈值分类 → bbox）

## 质量验收清单（出图后逐项过）

- [ ] 所有链标签可见且无遮挡（视觉评估确认）
- [ ] 残基标签无两两重叠
- [ ] 虚线颜色为黄色（低分辨率预览时可能显暗色，正式图必须 3200 宽）
- [ ] 配体在框内完整、未被框线切割标签
- [ ] 红框参数与正文数字一致（BE 保留 1 位小数）
- [ ] 预测残基带 `*`、实验残基无 `*`
- [ ] 透明版背景真透明（ray_opaque_background 0）
